# SNBD HOST product links

Public links for the marketing site. Visitors can configure without logging in; they sign in or register at checkout, then go to the payment screen.

Optional query parameters: `?cycle=annually` (or monthly, triennially…), `?cur=USD` (prices in USD), `?lang=bn` (Bangla). WHMCS-style `/order?pid=<id>` and `/cart.php?a=add&pid=<id>` links also work.
